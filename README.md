### Régimen de aprobación de la materia

\

Se debe aprobar el prefinal. Para los alumnos que desaprueben el prefinal, habrá dos fechas de recuperación.
Para poder rendir el final además es preciso aprobar el taller.
Es imprescindible haber llenado la encuesta al final del verano para poder figurar en el sistema como aprobado, y es imprescindible hacer firmar el taller en la libreta para poder dar final.
La aprobación de la práctica y el taller es independiente, esto quiere decir que pueden aprobarse por separado en cuatrimestres distintos. \
 Una vez aprobados la práctica y el taller, puede rendirse el examen final.
